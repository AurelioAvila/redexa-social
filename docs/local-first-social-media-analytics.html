What local-first means here

The installed application stores statistics in your Windows app-data folder and communicates with official platform APIs. Online services handle authorization, purchases, license verification and updates; license records are stored remotely.

  • Supported credentials are protected with Windows DPAPI.
  • Insights are computed locally without AI API calls.
  • History, posting-window charts and CSV exports require Pro or Studio.

A clearer view across platforms

Instead of opening separate analytics products, creators can compare recent activity, audience movement, high-performing content and posting windows from one interface. A platform problem does not prevent the remaining connected accounts from being useful.

Privacy with honest boundaries

Local encryption protects copied databases and data opened under a different Windows account. It cannot protect against malware already running as you on the same computer. Redexa Social documents that boundary instead of presenting local storage as an absolute security guarantee.
