Your data stays on your computer

Account permissions and every statistic Redexa Social shows live in a local database on your machine, outside the app folder so updates never touch it. The app talks directly to each platform's official API using a token you grant yourself, and you can revoke it at any time from that platform's own security settings — the only exception is the Instagram/TikTok OAuth token exchange, routed through a minimal proxy that never sees your data.
