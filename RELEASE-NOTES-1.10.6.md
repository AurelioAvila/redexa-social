Redexa Social 1.10.6 introduces the Channel desk workspace, with clearer navigation and a more focused view of your connected channels.

- Refined typography, spacing and controls across the workspace, with the existing themes and app icon preserved.
- The Windows title bar follows the selected theme for a more consistent desktop window.
- Account setup is separated from connection problems, so an unlinked channel is no longer presented as a technical failure.
- Loading placeholders and inline refresh progress make ongoing work easier to follow. Existing results stay visible while refreshing.
- Improved layouts for smaller windows and clearer primary and secondary actions.

The existing automatic updater and compatibility launcher are retained.
