Redexa Social 1.11.1 keeps future updates arriving. Please install it.

- The updater now looks for new versions on redexa.getcertsprint.com first and falls back to GitHub, so update delivery can move to our own servers without leaving this copy behind.
- The app now trusts a second update-signing key, kept offline, alongside the current one. This release is still signed with the current key. A later release will switch to the new key; copies older than 1.11.1 will then need the installer from the website, while this one keeps updating itself.

Nothing else changes: same features, same data, same installer. Official downloads carry verified Aurelio Avila publisher signatures with trusted timestamps, and the existing updater signature. Connected accounts and local data are retained.
