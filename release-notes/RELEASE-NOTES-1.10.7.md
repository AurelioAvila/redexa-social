Redexa Social 1.10.7 improves desktop update notifications.

- Available updates now open a compact dialog at startup, with clear install and postpone actions.
- Each application launch checks for a new signed release instead of letting yesterday's cached result hide it for up to 24 hours.
- Remind me later and Skip this version remain respected. Downloads only start after choosing Install and restart.
- Keyboard navigation, closing the dialog and retrying a failed install are supported.

Publisher signatures and signed updater manifests remain required. Older versions may still show their existing update button until this version is installed.
