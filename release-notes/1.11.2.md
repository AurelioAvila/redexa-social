Redexa Social 1.11.2 makes sure test-version users keep getting every update.

- If you turned on "Receive test versions", the app now also checks for regular releases and installs whichever is newer. Before, a missing test version meant no updates at all, including fixes.
- "Email support" in Account now writes to the product inbox, redexasocial@getcertsprint.com, the same address as the website and our emails.

Nothing else changes: same features, same data, same installer. This release is still signed with the current update key. Official downloads carry verified Aurelio Avila publisher signatures with trusted timestamps, and the existing updater signature. Connected accounts and local data are retained.
