Redexa Social 1.10.8 makes desktop updates quieter.

- The bundled updater now runs without opening a console window.
- Update diagnostics remain in the local update log. If an update fails after the app closes, a normal Windows message points to the details.
- Signature verification, backups and automatic rollback remain in place.

This change applies to updates started by 1.10.8 and later: older installed copies still use their existing updater for the transition to this release.
