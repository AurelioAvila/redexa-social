Redexa Social 1.10.9 protects the local desktop API, reserves its loopback port before opening the window and encrypts managed database backups.

- Local private API requests require an authorization token generated for the running app. Public version checks remain compatible with existing updaters.
- The app binds its local port before opening a browser or desktop window, preventing another process from claiming that port first.
- Managed backups are protected with Windows encryption; startup stops if migration or backup protection fails.
- Retires the publicly callable password-change email endpoint. Normal sign-in, password-reset and welcome email flows are preserved.
- Includes recent branded email improvements.

Official Windows downloads require verified Aurelio Avila publisher signatures, trusted timestamps and the existing updater signature. Connected accounts and local user data are retained.
